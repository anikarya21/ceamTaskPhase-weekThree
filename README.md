# ceamTaskPhase-weekThree
This is for Ceam Task Phase - Week 2.

<br>

## Whole Pipeline
    - Specified parameters for shi tomasi corner detection

    - Specified parameters for lucas kanade optical flow

    - Masked the important locations to detect the features

    - Tracked maximum of 50 corners in every frame

    - Draw circles of color white where corners have been detected

    - Draw connecting line of the location of previous frame to the current frame and draw on a mask

    - If key 'C' is pressed then reset the mask to original

    - If key 'ESC' is pressed then exit
